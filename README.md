# Fast Recon Target Scanner

Простой и быстрый многопоточный инструмент на **Go** для проведения разведки (recon) и проверки доступности веб-сайтов. Утилита считывает список доменов из текстового файла, отправляет быстрые `HEAD`-запросы в несколько параллельных потоков (Worker Pool) и классифицирует ответы по HTTP статус-кодам.

## 🚀 Особенности

- **Многопоточность (Worker Pool):** Одновременная проверка сайтов в 20 независимых потоков (воркеров).
- **Синхронизация через `sync.WaitGroup`:** Надежная архитектура сбора результатов, гарантирующая полную печать логов перед завершением работы.
- **Корректная обработка URL:** Автоматическое добавление префикса `https://`, если он отсутствует в исходном файле.
- **Подмена User-Agent:** Запросы маскируются под стандартный браузер для снижения блокировок со стороны WAF.
- **Экономия трафика:** Используются `HEAD`-запросы вместо `GET`, чтобы не скачивать тело страницы.

## 🛠 Установка и запуск

1. Склонируйте репозиторий или скачайте исходный код.
2. Создайте в корневой директории файл `target.txt` и добавьте туда список доменов для проверки (каждый домен с новой строки, можно использовать комментарии через `#`).
3. Запустите программу с помощью команды:
   ```bash
   go run main.go
   ```

## 📋 Пример файла target.txt

```text
# Список целей для проверки
google.com
https://github.com
example.com
```

## 🔍 Логирование и статусы

Программа подсвечивает результаты в консоли с помощью префиксов:
- `[+] [200 OK]` — Хост активен и доступен.
- `[*] [3xx REDIRECT]` — Обнаружено перенаправление.
- `[!] [401/403 AUTH]` — Требуется авторизация (доступ ограничен).
- `[-] [XXX]` — Другие статус-коды (ошибки сервера или клиента).
- `[ERR]` — Ошибка подключения (таймаут, DNS-ошибка и т.д.).
